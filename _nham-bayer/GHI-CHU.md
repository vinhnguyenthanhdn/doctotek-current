# Bộ tài liệu này phân tích NHẦM sản phẩm

Các file trong thư mục này phân tích **web học viên Bayer** (`bayer-api`, `bayer-doctotek-app`). Đó là bản build riêng cho khách Bayer, không phải nền tảng cần viết lại.

Nền tảng cần viết lại là **web DoctoTek** (`edocjo-api`, `edocjo-mobile`). Tài liệu đúng nằm ở `working1/` (thư mục cha).

Chỉ nên dùng lại các phần chung về kỹ thuật (Flutter web vs React, HLS trên iOS, cache nginx, heartbeat keepalive), và phải đối chiếu lại với code DoctoTek.
